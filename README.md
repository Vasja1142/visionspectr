# VisionSpectr

Десктопное приложение для обработки изображений с акцентом на выравнивание перспективы, подготовку данных для ML-моделей и работу с датасетами.

##  Назначение

VisionSpectr — инструмент для:
- Выравнивания перспективы изображений (в том числе двойной перспективы для широких объектов)
- Геометрических преобразований (поворот, масштаб, ресайз)
- Подготовки изображений для обучения ML-моделей
- Разметки и аугментации данных (в разработке)

## 🛠 Стек технологий

- **Python 3.14**
- **PySide6** (Qt6) — графический интерфейс
- **OpenCV 5.0** — обработка изображений
- **NumPy** — математические операции
- **uv** — менеджер зависимостей и виртуальных окружений

## 📦 Установка

### Требования
- Python 3.14
- uv (https://docs.astral.sh/uv/)

## 🚀 Возможности

### Выравнивание перспективы

#### Режим 4 точки (обычная перспектива)
Для объектов, снятых под углом, которые можно описать четырьмя угловыми точками.

**Использование:**
1. Откройте изображение (`Ctrl+O`)
2. Выберите режим "4 точки (обычная перспектива)"
3. Кликните по 4 углам объекта (по часовой стрелке, начиная с левого верхнего)
4. Нажмите "Применить перспективу"

#### Режим 6 точек (двойная перспектива)
Для широких объектов, где левая и правая части имеют разную перспективу. Создаёт плавный переход между двумя выпрямленными половинами.

**Использование:**
1. Выберите режим "6 точек (двойная перспектива)"
2. Кликните по 6 точкам в порядке:
   - Верх-лево, верх-центр, верх-право
   - Низ-лево, низ-центр, низ-право
3. Нажмите "Применить перспективу"

### Геометрические преобразования

- **Поворот**: от -180° до +180° с живым предпросмотром
- **Масштаб**: от 10% до 300% с живым предпросмотром
- **Изменение размера**: точное задание ширины и высоты в пикселях
  - Автоматический пересчёт пропорций (опционально)
  - Качественная интерполяция Lanczos4

### Работа с файлами

- Открытие изображений: PNG, JPEG, BMP
- Сохранение результата: PNG, JPEG
- Автоматическое добавление расширения при сохранении

##  Разработка

### Добавление зависимостей

```bash
# Основная зависимость
uv add <package>

# Зависимость для разработки
uv add --group dev <package>
```

### Запуск приложения

```bash
uv run python -m visionex
```

### Форматирование кода

```bash
# Установка инструментов разработки
uv add --group dev ruff mypy pytest

# Форматирование
uv run ruff format .

# Проверка кода
uv run ruff check .

# Проверка типов
uv run mypy src

# Запуск тестов
uv run pytest
```

### Работа с Qt Designer

```bash
# Запуск дизайнера
uv run pyside6-designer

# Компиляция .ui файла в Python
uv run pyside6-uic src/visionex/main_window.ui -o src/visionex/main_window_ui.py

# Компиляция ресурсов
uv run pyside6-rcc resources.qrc -o resources_rc.py
```
